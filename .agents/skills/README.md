# 项目内 DSH 文档 skills

此目录保存三个可独立于评估源码目录使用的 skill：`dsh-doc-writing` 负责结构与管理，`dsh-prose-standard` 负责行文规范，`dsh-trim-cot-leakage` 负责清理写作过程残留。每个目录包含原有引用资源，文档编写 skill 还包含完整模板。

来源：[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness/tree/39163dd30f703a79079e2d2446545cff3c453738/.agents/skills)，版本 `39163dd30f703a79079e2d2446545cff3c453738`。各目录保留上游 MIT LICENSE；原评估目录中的文件未修改。

本地调整仅包含：每个 SKILL.md 增加项目适用说明；通用文档规则引用本项目的 docs/AGENTS.md；技能正文和参考页中未随副本复制的 DSH 专属资料改为固定版本的上游链接。示例和模板保留上游内容，模板中的占位链接在实际使用时替换。上游脚本命令是 DSH 流程资料，不代表本项目存在相应命令。

项目当前使用中文单语，规划与已实现能力分开；具体规则由 [docs/AGENTS.md](../../docs/AGENTS.md) 维护。后续修改项目内副本，不修改评估源码中的原件。
